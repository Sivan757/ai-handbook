# 术语表

同一个概念只用一种叫法。这张表是全文检查的依据，写错会被 `pnpm lint` 拦下。

## 用哪个词

| 用这个 | 不要用 | 说明 |
|---|---|---|
| 任务简报 | 提示词包、提示词模板、prompt 模板、需求描述模板、任务描述 | 给 AI 布置独立任务时按五格（目标、背景、约束、验收、输出）写的那段话 |
| 交接单 | 交接说明、交接摘要 | 长会话聊乱或换人接手时写的交接文件；章节和模板页标题用「会话交接」，正文与文件内统一称交接单 |
| 项目指令 | 项目配置、项目规则、AGENTS 文件、CLAUDE.md 文件、规则文件 | 仓库或工作区根目录里给 AI 看的长期约定。具体文件名照实写 AGENTS.md |
| 全局指令 | 全局规则、个人指令、系统提示词、人设 | 个人跨所有项目生效的通用习惯，放在工具个人配置里 |
| 系统提示 | — | 工具自带的行为规则与工具清单，区别于用户自己写的全局指令与项目指令 |
| 技能 | skill 包、技能包 | 按需加载的专项流程说明；打包工具统一写作 skill-creator（可注部分工具叫 skills-creator） |
| 项目技能 | 团队技能 | 跟着代码一起提交进 Git 仓库、给全组共用的按需技能 |
| Harness | 运行框架 | 能接通本地文件、命令与浏览器等工具的 AI 工作台；首次出现可用「工作台」或「架子」作中文括注 |
| 智能体 | AI 智能体、AI Agent、编程 Agent、agent 智能体、AI 代理、代理程序 | 带着 Harness 能调工具、分步干活的 AI。泛指时用智能体（可带括注 Agent），具体产品名照写 |
| 子代理 | teammate、子会话、subagent | 主会话派出去、拥有独立上下文的助手会话 |
| 会话 | 对话窗口、聊天会话 | 一次连续的对话 |
| 上下文 | 语境、context 窗口、上下文窗口 | 一次请求里模型能看到的全部内容 |
| 上下文工程 | 上下文管理、prompt 工程 | 决定哪些内容进入上下文 |
| 验证 | 校验一下、核实过程 | 用可执行的方式或对照原始依据确认结果对不对 |
| 未验证 | 待核实、未找到依据、未核对 | 查不到原始出处或尚未实测确认时的统一占位标记 |
| 验收标准 | 验收条件、验收标准描述、完成定义、验收判据 | 事先约定的可核对完成判据（任务简报五格栏位简标为「验收」） |
| 自查 | 自检 | 交稿或交付前对照清单先核对一遍 |
| 合并请求 | MR 请求、Pull Request 请求、PR 单 | MR、PR 可以作为缩写出现，但正文概念统一叫合并请求 |
| 保护分支 | 主干分支 | 禁止直接推送、必须经合并请求合入的长期分支（如 master / main、release、dev） |
| 特性分支 | 功能分支、feature 分支的中文混写 | 从长期分支拉出来做一件事的临时分支 |
| 工作树 | 工树 | git worktree 开出的独立工作目录，用来多分支并行开发 |
| 约定式提交 | 规范提交 | 按「类型(范围): 描述」书写的 Git 提交信息规范 |
| 复盘 | 回顾会议纪要、postmortem 报告 | 事后按「发生了什么、怎么恢复的、错在哪、下次怎么做」四节写的记录 |
| 决策记录 | 架构决策记录 | 按「背景、决定、否掉的方案、后果」写下的选型记录，工程里常简称为 ADR |
| 踩坑记录 | 坑记录、问题记录 | 日常踩坑或取舍用的五行卡片（以为、实际、原因、怎么看出来、以后） |

## 不写的词

| 词 | 为什么 | 改成 |
|---|---|---|
| 作者 | 第一人称写，用「我」 | 我 |
| 读者们 | 不用复数呼语 | 你 |
| 大家 | 指代不清，写清是谁 | 你 |
| 众所周知 | 假设读者已知，去掉 | 删掉 |
| 显而易见 | 同上 | 删掉 |
| 值得注意的是 | 填充词 | 删掉 |
| 需要注意的是 | 填充词，直接写要注意什么 | 删掉 |
| 综上所述 | 填充词 | 删掉 |
| 核验 | 编辑过程的词，不进正文 | 验证 |
| 待确认 | 编辑状态不进正文 | 删掉 |
| 本文将 | 元叙述 | 删掉 |
| 本文档旨在 | 元叙述 | 删掉 |
| 这一章解决什么 | 模板开头，读起来像模型在交作业 | 换成一句把人带进场景的话 |
| 本节将 | 元叙述 | 删掉 |
| 总而言之 | 填充词 | 删掉 |

## 怎么执行

这张表由 `tools/glossary.json` 生成，改词请改 JSON 再跑 `pnpm run glossary`。

推送前跑一次：

```bash
pnpm lint      # 术语、禁用词、错别字、标点、空格、标题、代码块、句段长度
pnpm freshness # 每页的复核日期与过期页
```
