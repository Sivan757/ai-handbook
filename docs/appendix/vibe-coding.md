# 网页示例与词表

非研发同事让 AI 做小工具时，常遇到两个结果。要么做出来的网页只有丑陋的输入框，要么 AI 默认给你建起前后端十几个文件，连本地怎么启动都折腾半天。

问题往往在于你给的词太抽象。「做个好看、能互动的网页」，模型只能照普通表单瞎猜。只要在指令里加上准确的技术词汇和「单文件 HTML」约束，一个双击就能在浏览器打开的文件，就能做出接近专业软件的效果。

## 三个交互示例

下面三个演示没有连任何后台服务器，全部依赖浏览器原生能力或前端脚本跑起来。切换标签可以直接点按、拖拽试玩，下方附带对应的提示词配方。

<VibeShowcase />

三类典型需求对应不同的技术起点：

- **日常办公提效**：合并台账、核对明细、看趋势图，用单文件 HTML 配合前端表格和图表库最快，发给同事就能用。
- **创意与交互演示**：做声音合成、动画或教学演示，浏览器自带的 `Web Audio API` 和 `Canvas` 就能完成，不用装额外软件。
- **三维与工程文件预览**：在线看 3D 零件或 CAD 模型，提示词里直接点名 `Three.js`、`OrbitControls` 或 `OpenCascade.js`，AI 才不会自己硬算几何图形。

## 技术词汇地图

写提示词时，把脑海里的形容词替换成下面这几张表里的标准技术名词，AI 的产出上限会明显拉高。

### 页面布局与视觉形态

| 你想实现的效果 | 要对 AI 说什么词 | 适合什么场景 |
|---|---|---|
| 手机和电脑屏幕都能自动排好 | 响应式布局（Responsive） | 表单、展示页、手机端查看的看板 |
| 卡片高低错落自动填满列宽 | 瀑布流布局（Masonry） | 素材库、灵感墙、长短不一的摘要卡 |
| 左边列目录、右边看详情和编辑 | 左右分栏工作台 | 文档预览、多条审批对比、配置编辑 |
| 点一条记录从侧边滑出详情 | 抽屉弹窗（Drawer） | 不想跳转页面时查看明细或修改字段 |
| 自动或手动切换浅色与深色界面 | 暗黑模式（Dark Mode） | 长时间盯屏用的统计或调试工具 |
| 少写样式代码又能保持版面整齐 | CDN 引入 Tailwind CSS | 快速做出干净现代的卡片和按钮 |

### 交互控制与数据留存

| 你想实现的效果 | 要对 AI 说什么词 | 适合什么场景 |
|---|---|---|
| 把本地文件直接拖进网页框里 | 拖拽上传（Drag & Drop） | 批量导入 Excel、CSV、图片或模型 |
| 打字时表格或卡片立刻筛选 | 实时搜索过滤与防抖（Debounce） | 几百条数据里快速找客户或单号 |
| 关掉网页再打开，填写内容还在 | `localStorage` 本地持久化 | 待办清单、草稿暂存、偏好设置 |
| 浏览器里存大量历史表格或图片 | `IndexedDB` 本地数据库 | 单机离线小工具，不建后端服务器 |
| 几千条列表滑动时不卡顿 | 虚拟滚动（Virtual List） | 大批量明细核对、长日志预览 |

### 表格、图表与文档导出

| 你想实现的效果 | 要对 AI 说什么词 | 适合什么场景 |
|---|---|---|
| 网页直接读取并导出 Excel | `SheetJS`（`xlsx` 库） | 合并报名表、洗数据后导出总表 |
| 画柱状图、折线图、饼图或仪表盘 | `ECharts` 或 `Chart.js` | 周报数据看板、各部门预算对比 |
| 自动画流程图、时序图或架构图 | `Mermaid` | 梳理审批链、业务流转示意 |
| 在网页里直接翻阅 PDF | `PDF.js` | 合同预览、内部手册附带查看器 |
| 把网页排版好直接导出为 PDF | 打印样式 `@media print` | 报销单、证明函、一页式简报 |

### 图形、声音与工程预览

| 你想实现的效果 | 要对 AI 说什么词 | 适合什么场景 |
|---|---|---|
| 网页里画自定义图形或交互画板 | `Canvas 2D` 或 `SVG` | 签名板、标注工具、简单数据图 |
| 在线旋转查看 3D 物体或场景 | `Three.js` 与 `OrbitControls` | 产品 3D 展示、空间布局预览 |
| 不下载音频文件直接合成声音 | `Web Audio API` | 虚拟钢琴、节拍器、提示音工具 |
| 浏览器里打开和查看 CAD 零件 | `OpenCascade.js` 或 `STL` 解析器 | 硬件/制造团队在线看三维图纸 |

## 单文件用 Git 存档

用 AI 改单文件 HTML，最常见的崩溃发生在第三四轮。前面明明做通了导出，下一轮让它「顺手调下样式」，导出按钮却突然点不动了。

不需要懂团队协作那套分支流程，只要把你的单个 `index.html` 放进单独文件夹，顺手用上三条 Git 命令，每改通一步就存一个档：

1. **建好文件夹后初始化存档库**（每个工具只需做一次）：

```bash
git init
```

2. **每改通一个小功能就存一个档**，或者直接让 AI 帮你跑这两句：

```bash
git add index.html
git commit -m "跑通 Excel 读取和柱状图展示"
```

3. **这一轮 AI 改崩了，一键退回上一个正常版本**：

```bash
git checkout -- index.html
```

存完档再开下一轮对话提新需求。这样哪怕改砸十次，一秒钟就能退回刚才还能用的那一版，再也不用重头再来。
