# 书单

## 怎么读

1. 先做一遍检视阅读，选出要读的章节。方法见 [阅读](/foundations/04-read)。
2. 每章读完，写三句话。
3. 挑一条做法，这一周用一次。
4. 读完，在周会上用五分钟讲给别人听。
