# 笔记与清单

![左边是线装笔记本和串起的索引卡，右边是带勾选框的木质清单板](../images/f06-notes-checklist.jpg)

人的脑子最擅长想点子、做判断，最不擅长同时死记一堆细节。工作里经常碰上两件头疼事，一是几个月前明明踩过一次坑、好不容易琢磨透的门道，过三个月又从头栽一遍；二是明明熟得不能再熟的流程，临交稿偏偏漏掉了最不该忘的那一步。

靠嘴上念叨「下次一定记住」几乎没用。把这两件事拆给两件外接工具去扛最省力，**笔记负责留住好不容易想明白的事，清单负责挡住熟手也会犯的低级漏步**。

## 写下来不是为了收藏，是为了逼自己想明白

很多人记笔记的习惯是看到一段好话就复制粘贴，存进网盘再也不打开。攒了几百篇收藏，真正要用的时候脑子里还是空白。

人很容易有一种错觉，觉得自己心里想明白了，嘴上也就讲得出来。《暗时间》里专门拿「书写是为了更好地思考」讲过这个毛病，很多时候我们以为已经想透的事，真动笔写下来，立刻就会发现前后因果根本接不上。**动笔写从来不只是抄一遍现成想法，它是在逼着我们把藏在深处的未知显现出来。**

《卡片笔记写作法》进一步把笔记分成三种，弄清分工后就不会再变成只进不出的杂物间：

1. **闪念笔记**：开会或干活时突然想到的线索，先拿便签或聊天框记下来，定期整理后删掉。
2. **文献笔记**：读报告、看书或者问完 AI 有收获时，用一两句话**按自己的理解重新转述**，少做整段复制粘贴。
3. **永久笔记**：一条卡片只写一个独立的想法或经验。写完后立刻翻一下自己以前的笔记，看看它和哪一条有关、哪一条冲突，**顺手把链接挂上去**。靠笔记之间的链接串成一张网，比纠结该新建哪个分类文件夹耐用得多。

碰到一堆乱麻一样毫无头绪的新问题时，也可以先借《程序员的思维修炼》6.8 节讲的**思维导图**发散一遍。先把散在各处的要素铺在一张纸上归好类，再转成有条理的文字卡片。

## 记工作里的落差，五行就够用

如果只记「今天干了啥」，三个月后一条也用不上，翻聊天记录和日报就行。真正值得花三分钟写下来的，是工作里的**落差**：当时以为是怎么回事，查到底发现实际是怎么回事，以及下次怎么一眼认出来。

| 值得记的四类 | 写什么内容 | 办公日常例子 |
|---|---|---|
| 踩过的坑 | 以为是什么、实际是什么、怎么看出来 | 以为月度汇总表少了八万是公式漏行，实际是原表开启了筛选隐藏了退单行 |
| 做过的取舍 | 选了哪条路、否掉了什么、为什么否 | 活动报名改用在线表单直连汇总表，否掉手工回收 Excel，因为每次合并都要花半天去重 |
| 推翻的旧认知 | 原本信的哪条规律不成立，新依据是什么 | 原以为客户只要在 CRM 里改了状态就会同步开票表，核对才发现两张表每周五才手动导一次 |
| 文档与实际不符 | 制度或手册写什么、现场实际怎么跑 | 新人指南写报销月底截单，财务实际改成每周五中午十二点前提交 |

反过来，有几样东西没必要往永久笔记里堆。很快就会过期的现状快照（比如「本月有 4 个活动在跑」）、进系统一查就有的数据，以及会议纪要里已经记过一遍的决定副本。

记录一条踩坑经验不用写长文，按下面这五行留下来，三个月后任何人扫一眼都能直接上手：

```markdown
# 销售月表对不上总账先查隐藏行与筛选

以为：汇总公式少加了最后几行。
实际：原表里有人设了按大区筛选，带公式的合计数把被隐藏的行跳过去了。
原因：SUM 函数默认把隐藏行也算进去，但复制可见单元格时很容易漏掉隐藏区。
怎么看出来：打开原表看左侧行号是不是连续，跳号说明有筛选或隐藏。
以后：拿到别人发来的表准备做汇总前，先点「全部显示」并取消隐藏行再动公式。
```

## 用清单挡住「会做却漏了」的错

记好了经验，真忙起来还是会漏步。《清单革命》里把人犯的错分成了两类。一类是 **无知之错**，没掌握相关知识，这靠学习、查资料和请教来解决。另一类是 **无能之错**，道理全懂、流程也走过几十遍，却偏偏在赶时间或者被人打断的那一刻跳步了。飞行员起飞前再熟练也要逐条过单子，因为单靠人的自觉，拦不住「走神」和「以为自己做过了」。

清单要管用，写的时候必须克制。一份好清单通常只留五到九项，控制在两分钟内能过完，专门挑那些**平时容易忘、漏了代价又大**的关键点，不要把整本操作手册抄进来。更重要的是，每一条都得写成能干脆答出「做了还是没做」的动作，同时标清楚什么时候用。熟练的日常工作适合做完交稿前集中扫一遍（做完再核对），不常干又没法撤回的大动作就得看一条做一条（边读边做）。

拿每月给客户发对账表举例，如果清单写成这样，其实等于白写：

- 注意检查表格数据，确保别算错
- 发之前确认格式美观、没有敏感信息

换成真能拦住问题的写法，大概长这样：

**发客户月度对账表前（边读边做）**

- [ ] 取消原表所有筛选和隐藏行，确认没有漏算区域
- [ ] 总金额与上月结转额拉回财务总账复算一致
- [ ] 删掉工作簿里夹带的内部成本测算 Sheet
- [ ] 另存为 PDF 再核一眼分页，确认最后一列没有被裁掉

## 接手前和发出前，直接拿去用的清单

下面这两份清单，平时接活和交稿时可以直接拿去套用，再按自己岗位的常见疏漏增删条目。

### 接手一项新任务前

### 正式提交或群发前

<Checklist id="before-send" :items="[
  '打开最终导出的文件亲眼看一眼排版和分页，不凭印象放行',
  '关键合计数、日期和引用条款拉回源头核对过一遍',
  '检查改动范围，确认没把原有的正文或公式悄悄带坏',
  '对照开工时约定的目标和截止时间，确认没有漏项',
  '先留一份带当天日期的副本，出了差错能立刻退回'
]" />

如果是准备群发重要客户、或者要修改多人同时用的共享总表，还可以按这个短单边读边过一遍：

- [ ] 先备份了一份带今天日期的副本，改坏了能一秒退回
- [ ] 收件人、抄送人和可见范围确认无误，附件没有夹带内部测算页
- [ ] 对外承诺的日期、金额和口径，已由对应负责人确认过

日常小事用不着事事拿单子打钩，真正容易出岔子、漏了又不好补救的事才需要照着过一遍。每次按单子跑完还是漏了一项，或者业务改了新规，当天就顺手把那一条补进去、把过时的划掉。

## 练习

1. 从过去两周的返工或踩坑里挑一件，按「以为、实际、原因、怎么看出来、以后」写一张五行卡片，放进你最顺手的笔记里并挂上一个旧笔记的链接。
2. 挑一件你每周都要重复交付的常规工作，写一份不超过七项的「做完再核对」清单，下周交付前照着过一遍。
3. 把你现在手头正在用的一份检查清单拿出来过一遍，删掉「仔细核对」这类空话，把每条都改成能干脆答出「做了还是没做」的具体动作。

## 延伸阅读

- 《暗时间》：读第二篇「思维改变生活」里的「书写是为了更好地思考」，中文。这一篇把「为什么写下来才能暴露思考漏洞」讲得最透。
- 《卡片笔记写作法》：读第二章「有效写作的四个基本原则」和第三章「成功写作的六个步骤」，中文。闪念、文献、永久三种卡片怎么流转、为什么链接比死分类管用，全在这两章。
- 《清单革命》：读引言「无知之错」与「无能之错」，以及第二部分第 4 至 7 章，中文。不到三小时就能读完，讲透怎么把「做完再核对」和「边读边做」用进日常工作里。
