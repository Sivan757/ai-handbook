# 视频课表

通勤、排队、等编译，看视频。坐下来，读文字。两种场景，两种材料。

这一页按主题列出精选视频。每行写明时长、语言、看哪一段和对应章节，帮你把零散时间用在最值得看的片段上。

## 怎么看

看视频最容易变成「看完了就等于会了」。照这三条做：

1. 一次只看一个。看之前，先读对应章节，带着问题看。
2. 看的时候暂停。自己先想下一步，再看讲的人怎么做。
3. 看完写三句话：讲了什么、和自己原来想的有什么不同、明天改哪个做法。
